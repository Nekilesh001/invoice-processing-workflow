\# Invoice Processing Workflow



Hands-on implementation of an AI-powered invoice processing workflow based on the Agentic AI course from DeepLearning.AI by Andrew Ng.



\## Current Workflow



Invoice PDF

→ PDF to Text

→ LLM

→ Extract Required Fields

→ Update Database

→ Record Created



\## Required Fields



\- Biller

\- Biller Address

\- Amount Due

\- Due Date
